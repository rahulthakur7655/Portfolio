📁 Public Folder — Required Files
===================================

To make the portfolio fully functional, please add these files here:

1. profile.png  (or profile.jpg)
   → Your profile photo
   → Recommended: 400x400px or larger, square crop, good quality
   → The site will show an auto-generated avatar as fallback if missing

2. resume.pdf
   → Your resume in PDF format
   → Used in Navbar "Resume" button, Resume page download button

Both files go directly in this /public folder.
